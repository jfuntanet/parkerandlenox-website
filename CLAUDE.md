# parker-lenox-site — parkerandlenox.com (sitio público)

Next.js. Sitio público de Parker & Lenox.

## Comandos
- Logs: `docker logs parker-lenox-site -f --tail=50`
- Rebuild: `docker compose -f /opt/parker-lenox-site/docker-compose.yml up -d --build`
- Shell: `docker exec -it parker-lenox-site sh`
